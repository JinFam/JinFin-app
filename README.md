# JinFinance (공유 앱 셸)

백엔드 없는 정적 가계부 앱. **이 저장소에는 실제 재무데이터가 없습니다** — 앱 코드(HTML/CSS/JS)와 더미 시드뿐입니다.

실제 데이터는 각자의 **비공개** GitHub 저장소에 저장되며, 브라우저에 입력한 **개인 토큰(PAT)** 으로만 접근됩니다. 토큰은 브라우저 localStorage에만 저장되고, 이 저장소/코드/커밋에는 절대 포함되지 않습니다.

## 모바일/PC에서 사용
1. 배포된 페이지(GitHub Pages URL)를 브라우저에서 엽니다.
2. 우하단 동기화 바에 GitHub 토큰과 이름을 입력하고 **연결**.
3. 비공개 저장소의 데이터가 실시간(5초 폴링)으로 표시됩니다.

토큰이 없으면 더미 예시 데이터만 보이며, 어떤 개인정보도 노출되지 않습니다.
